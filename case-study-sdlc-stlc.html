QA Documentation Case Study

SDLC & STLC Study

A learning/documentation case study showing how QA activities fit into the software development lifecycle.

SDLC

Requirements → Planning → Design → Development → Testing → Deployment → Maintenance.

QA contributes early through requirement review and continues through testing, release readiness and maintenance.

STLC

Requirement Analysis → Test Planning → Test Case Development → Test Environment Setup → Test Execution → Test Closure.

Each phase produces useful testing outputs and checkpoints.

Practical QA Connection

I use this lifecycle knowledge to plan test scenarios, identify risks, prepare test data, execute cases, report defects and summarize results for projects in my portfolio.
